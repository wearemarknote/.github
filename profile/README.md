# Marknote

**Your markdown studio for Windows.** Multi-tab editing, a live preview with maths and diagrams, wiki-linked notes, every to-do in one place, and git from the sidebar — with your notes staying plain `.md` files in a folder you chose.

- **Get it:** [Microsoft Store](https://apps.microsoft.com/detail/9NQKDFXH3Z6J) · [marknote.md](https://marknote.md)
- **What's new:** [Changelog](https://marknote.md/changelog) · [Roadmap](https://marknote.md/roadmap) · [Service status](https://marknote.md/status)
- **Marknote Sync:** end-to-end encrypted sync across your devices, in private beta — [join the list](https://marknote.md/beta)

| **Themes** — one file of colours, no code | [marknote.md/themes](https://marknote.md/themes) | [Make a theme](https://marknote.md/themes/build) | [wearemarknote/themes](https://github.com/wearemarknote/themes) |

Themes and plugins are free for everyone. A submission is a pull request; each repo's template is the review checklist, and a workflow validates your file exactly as the app will.

## Found a bug, want a feature?

[wearemarknote/issues](https://github.com/wearemarknote/issues) is the public tracker. Marknote's **About → Report a bug** pre-fills an issue with the version and OS for you — you review everything before it's posted. Or write to [support@marknote.md](mailto:support@marknote.md).

## Principles

- **Plain files.** Notes are markdown on your disk. No database, no proprietary format, nothing to export when you leave.
- **Nothing phones home.** No analytics, no telemetry, no account unless you opt into Sync — [the privacy policy](https://marknote.md/privacy) lists every request the app makes.
- **Encrypted means encrypted.** Marknote Sync encrypts on your device with a passphrase only you hold; the service stores what it cannot read.
